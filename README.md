# 🔐 Password Strength Checker

A simple Python project that evaluates password strength using basic security rules.

## 🚀 Features

- Checks password length
- Checks uppercase and lowercase letters
- Checks numbers
- Checks special characters
- Gives a password strength score from **0/5 to 5/5**
- Classifies passwords as **Weak, Medium, or Strong**
- Provides suggestions for improving weak passwords

## 🛠️ Technologies Used

- Python 3
- Regular Expressions (`re`)
- Git & GitHub

## ▶️ How to Run

Run the program using:

    python password_checker.py

Then enter a **dummy password** when prompted.

Example:

    === Password Strength Checker ===
    Enter a password to check: Cyber@Secure123

    --- Result ---
    Strength: Strong
    Score: 5/5
